# सजावट व्हिडिओ (आरास) — इथे खरी फाइल टाका

होम पेजवर आता एक व्हिडिओ सेक्शन आहे: **"गणपती आयुध सजावट आरास"** — हा सर्व २३
आयुधांच्या (कुठल्याही एका आयुधाचा नाही) संपूर्ण सजावटीचा/मखराचा व्हिडिओ आहे,
त्यामुळे तो कुठल्याही एका item-XXX फोल्डरमध्ये नसून इथे वेगळा ठेवलाय.

सध्या ही फाइल गैरहजर आहे (कोणतंही फुटेज उपलब्ध नव्हतं, आणि स्थानिक व्हिडिओ-जनरेशन
टूल्स नाहीत) — त्यामुळे साइटवर आत्ता "सजावटीचा व्हिडिओ लवकरच जोडला जाईल" असा
graceful मेसेज दिसेल (audio placeholder सारखाच पॅटर्न).

## खरा व्हिडिओ जोडायचा कसा

1. फोनने संपूर्ण मखर/आरास (सर्व २३ आयुधे दिसतील असा) व्हिडिओ शूट करा — आडवा
   (landscape) आणि जास्तीत जास्त १५–३० सेकंद ठेवा (मोठी फाइल संथ लोड होईल).
2. फाइलचं नाव बदलून **`aaras.mp4`** करा आणि इथे ठेवा (ही फाइल replace करेल):
   `media/decoration/aaras.mp4`
3. ऐच्छिक: एक थंबनेल फोटो `media/decoration/poster.jpg` म्हणून ठेवला, तर
   `data.json` मधल्या `meta.decoration_video.poster` मध्ये
   `"media/decoration/poster.jpg"` असं टाका (सध्या रिकामं आहे).
4. लोकल टेस्ट: `python -m http.server 8080` → `http://127.0.0.1:8080/`
5. `git add media/decoration data.json && git commit -m "Add real decoration video" && git push`
   → १–२ मिनिटांत live.

शीर्षक/कॅप्शन मजकूर बदलायचा असल्यास `data.json` मधलं
`meta.decoration_video.title` / `.caption` एडिट करा.

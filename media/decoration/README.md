# सजावट व्हिडिओ (आरास) — इथे खरी फाइल टाका

होम पेजवर एक व्हिडिओ सेक्शन आहे: **"गणपती आयुध सजावट आरास"** — हा सर्व
आयुधांच्या (कुठल्याही एका आयुधाचा नाही) संपूर्ण सजावटीचा/मखराचा व्हिडिओ आहे,
त्यामुळे तो कुठल्याही एका item-XXX फोल्डरमध्ये नसून इथे वेगळा ठेवलाय.

सध्या फाइल्स गैरहजर आहेत — साइटवर आत्ता "सजावटीचा व्हिडिओ लवकरच जोडला जाईल" असा
graceful मेसेज दिसेल (audio placeholder सारखाच पॅटर्न).

## पायरी १ — व्हिडिओ शूट करा

फोनने संपूर्ण मखर/आरास (सर्व आयुधे दिसतील असा) व्हिडिओ शूट करा. लांबीवर आता
कडक मर्यादा नाही (पूर्वी १५-३० सेकंद सुचवलं होतं) — [tools/video-optimize.html](../../tools/video-optimize.html)
कितीही मोठी raw फाइल आपोआप दोन हलक्या आवृत्त्यांमध्ये संकुचित करतो, त्यामुळे मूळ
लांबी/साइजची चिंता करू नका.

## पायरी २ — ऑप्टिमाइझ करा (आवश्यक)

राव व्हिडिओ फाइल थेट इथे टाकू नका — आधी ऑप्टिमायझरमधून चालवा:

1. `tools/video-optimize.html` उघडा (लोकल सर्व्हरवरून — खाली पायरी ४ बघा).
2. "ffmpeg इंजिन लोड करा" → मग तुमचा raw व्हिडिओ ड्रॉप करा.
3. कॉपीराइट मजकूर हवं तसं बदला (डिफॉल्ट: `Developed by Nilesh — केवळ वैयक्तिक अवलोकनासाठी...`).
4. "ऑप्टिमाइझ करा" — यातून **तीन फाइल्स** तयार होतात:
   - `aaras.mp4` — HD आवृत्ती (कमाल ७२० लघु-बाजू, फोन/टॅब/डेस्कटॉप/बहुतांश स्मार्ट TV साठी)
   - `aaras-sd.mp4` — SD आवृत्ती (कमाल ४८० लघु-बाजू, संथ/मोबाइल-डेटा कनेक्शनसाठी — साइट आपोआप निवडते)
   - `aaras-poster.jpg` — थंबनेल (व्हिडिओ लोड होण्याआधी दिसणारा फोटो)
5. तिन्ही "⬇ डाउनलोड करा" करून **थेट** इथे सेव्ह करा (ब्राउझरचा डिफॉल्ट Downloads
   फोल्डर नाही — तो नक्की निवडा, कारण C: ड्राइव्हवर जागा शिल्लक नाहीये):
   `media/decoration/aaras.mp4`, `aaras-sd.mp4`, `aaras-poster.jpg`

एन्कोडिंग स्पेक (सर्व डिव्हाइस — फोन/टॅब/डेस्कटॉप/स्मार्ट TV — साठी): H.264 Main
profile, yuv420p, AAC-LC ऑडिओ, `+faststart` (पूर्ण डाउनलोड होण्याआधी प्ले सुरू
होतं). कॉपीराइट मजकूर व्हिडिओ फाइलच्या मेटाडेटामध्ये embed होतो, साइटवरच्या
कॅप्शनमध्येही दिसतो.

## पायरी ३ — poster आधीच वायर्ड आहे

`aaras-poster.jpg` टाकल्यावर वेगळं काही करायची गरज नाही — `data.json` मधलं
`meta.decoration_video.poster` आधीच त्या पाथकडे पॉइंट करतंय.

## पायरी ४ — लोकल टेस्ट व पब्लिश

```
python -m http.server 8080
```
→ `http://127.0.0.1:8080/` वर उघडून बघा, मग:
```
git add media/decoration data.json && git commit -m "Add real decoration video" && git push
```
→ १–२ मिनिटांत live (तुमच्या README च्या नेहमीच्या पॅटर्नप्रमाणे).

## डाउनलोड-प्रतिबंध — प्रामाणिक टीप

साइटवरचा व्हिडिओ प्लेयर उजवं-क्लिक "Save video as" रोखतो आणि native डाउनलोड
बटण लपवतो — पण ही फक्त सर्वसामान्य प्रेक्षकांसाठी सोय आहे, खरं DRM नाही. ब्राउझरला
व्हिडिओ प्ले करण्यासाठी फाइल fetch करावीच लागते, त्यामुळे कोणीही dev-tools/
network-tab मधून थेट लिंक शोधू शकतं. खरं संरक्षण (EME + license server) एका
साध्या GitHub Pages साइटवर शक्य नाही.

शीर्षक/कॅप्शन/कॉपीराइट मजकूर बदलायचा असल्यास `data.json` मधलं
`meta.decoration_video.title` / `.caption` / `.copyright` एडिट करा.

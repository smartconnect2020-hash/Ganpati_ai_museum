चालवून परत बनतो, त्यामुळे git मध्ये track होत नाही (फक्त हा README ट्रॅक होतो,
जेणेकरून ही माहिती कुठेही हरवणार नाही). डिजिटल कॅटलॉगमध्ये सध्या **२०
आयुधं + १ home** = एकूण २१ QR आहेत (३ बंद केलेली — कवच/खंजीर/पुष्पबाण —
`../backup-removed-items-2026-09-13/` मध्ये backup आहेत).

## Canva मध्ये कुठलं वापरायचं?

- **तयार डिझाईन तसंच हवं, फक्त प्रिंट करायचंय** → `print-sheet-A4-side-label.pdf` थेट प्रिंट करा (100%/actual size, "fit to page" नको).
- **प्रत्येक आयुधाचं वेगळं कार्ड Canva मध्ये बनवायचं, आमचं design तसंच ठेवून** → `side-label-tiles/` मधली PNG एकेक करून टाका.
- **स्वतःचं संपूर्ण वेगळं डिझाईन बनवायचं, फक्त QR आमचा हवा** → `qr-only-color/` मधली नावाशिवाय PNG वापरा.
- **Canva मध्ये edit करताना:** आकार proportionally (aspect-ratio लॉक) बदलणं सुरक्षित; ओढून ताणणं (stretch), वर filter/opacity/shadow टाकणं, किंवा पांढरा quiet-zone मार्जिन कापणं — यामुळे स्कॅन फेल होऊ शकतो. edit केल्यावर एकदा फोनने स्कॅन करून खात्री करा.
